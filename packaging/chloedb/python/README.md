# chloedb (placeholder)

This release, 0.0.2, holds the name `chloedb` on PyPI for [ChloeDB](https://github.com/chloetech-ai/chloedb), an embedded search database with SQL. It is not ChloeDB: it contains no code, and importing it raises an error that says how to install ChloeDB.

Install ChloeDB's wheel from its GitHub release, where each `chloedb-py-v<version>` release has a wheel per platform. `--upgrade` replaces this placeholder if you installed it already:

```sh
pip install --upgrade chloedb -f https://github.com/chloetech-ai/chloedb/releases/expanded_assets/chloedb-py-v0.2.0
```

Once ChloeDB's releases are published here, `pip install chloedb` installs the real package, whose versions (0.2.1 and later) are above this one.
