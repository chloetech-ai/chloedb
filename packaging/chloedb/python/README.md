# chloedb (placeholder)

This release holds the name `chloedb` for [ChloeDB](https://github.com/chloetech-ai/chloedb), an embedded search database with SQL. It contains no code: importing it raises an error that says where to get ChloeDB.

Install a release from GitHub, where each `chloedb-py-v<version>` release has a wheel per platform:

```sh
pip install chloedb -f https://github.com/chloetech-ai/chloedb/releases/expanded_assets/chloedb-py-v0.3.0
```

(the newest release is at https://github.com/chloetech-ai/chloedb/releases).

Releases will be published here later.
