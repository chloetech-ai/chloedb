# chloedb placeholders

Version 0.0.1 of `chloedb` on PyPI, npm and crates.io holds the name for
[Strata](https://github.com/chloetech-ai/strata), an embedded search
database with SQL, until releases go out under it. The packages contain no
code: each says where to get Strata instead.

`.github/workflows/reserve-names.yml` publishes them, run by hand. Each
registry needs its setup first; the workflow's header says what.
