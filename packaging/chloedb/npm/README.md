# chloedb (placeholder)

This version holds the name `chloedb` for [Strata](https://github.com/chloetech-ai/chloedb), an embedded search database with SQL. It contains no code: importing it throws an error that says where to get Strata.

Install a release from GitHub, where each `strata-js-v<version>` release has a package per platform, for example:

```sh
npm install https://github.com/chloetech-ai/chloedb/releases/download/strata-js-v0.1.0/strata-db-0.1.0-darwin-arm64.tgz
```

The list of platforms is in [docs/strata/javascript.md](https://github.com/chloetech-ai/chloedb/blob/main/docs/chloedb/javascript.md). Releases will be published here later.
