# chloedb (placeholder)

This version holds the name `chloedb` for [ChloeDB](https://github.com/chloetech-ai/chloedb), an embedded search database with SQL. It contains no code: importing it throws an error that says where to get ChloeDB.

Install a release from GitHub, where each `chloedb-js-v<version>` release has a package per platform, for example:

```sh
npm install https://github.com/chloetech-ai/chloedb/releases/download/chloedb-js-v0.2.0/chloedb-0.2.0-darwin-arm64.tgz
```

The list of platforms is in [docs/chloedb/javascript.md](https://github.com/chloetech-ai/chloedb/blob/main/docs/chloedb/javascript.md). Releases will be published here later.
