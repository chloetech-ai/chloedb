What we do not claim

  • Not a sandbox. The gate decides what a credential may be used for; it does not contain the process.
  • Redaction is best effort for anything not registered as a credential. Black Box's canary sweep shows by how much.
  • Public sessions, not enterprise traffic. The trajectories are open benchmark runs.
  • Not a model-safety measurement. Current models mostly refuse injected orders, so Leak Lab assumes the attacker already won the prompt and counts what the credential handling still lets out. It does not measure how often models obey.
Every number on this page is a row in ChloeDB, written by a measurement run or parsed from a results file in the repository; nothing is typed into the page. Prototypes, not products. Code: prototypes/ in chloetech-ai/chloedb (Apache-2.0); Nodwyn is fclaude/nodwyn (Apache-2.0).
