How a line is traced

Deterministic, no model. An added, non-blank line of the final patch is traced when an edit call on that file holds the line exactly in the content it wrote. Ties go to the call that also wrote the neighbouring lines, then to the latest. The thread behind an edit is one graph statement over the steps' links: the edit's own output, the thought before it, the agent's latest views of that file and the latest failing output. Lines that only a shell command or a program the agent ran can account for are counted apart, not as traced.

What would a redactor have caught at ingest?

        
The sessions on this record were published as benchmark runs and donated traces. They hold no real credentials, so a count of "secrets caught" here would be a zero that says nothing. Instead, secrets are planted: example secrets from two public rule sets' own test data, and generated ones in no provider's shape, each placed into copies of four real tool outputs from this record. Four redactors run over the copies, and over every untouched step. A secret counts as caught only when every byte of it is removed.

The record is unchanged since our ingest

        
At ingest every step is hashed together with the hash of the step before it, each session ends in a head hash, and one root is taken over all the heads. The root is kept in a file outside the database it vouches for. Verifying means reading the rows back from ChloeDB and recomputing every hash.

Change one character and watch it fail

        
A session is copied to a scratch table, one character of one step is changed with an UPDATE, and the copy is verified. The record itself is not touched; the copy is deleted afterwards.

        

        

      

    

    

  


  
  

    

      
The data, and its licences

        
The four benchmark sets are samples of public datasets, shown under the terms on each dataset's card; the donated sessions are CC BY 4.0 and the Swival traces MIT. Dataset files are read as data: ChloeDB imports each Parquet file itself, and nothing from a dataset is executed.
